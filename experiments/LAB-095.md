### Interaction

1. Open original authored source
2. Export approved glTF/GLB
3. Import/play marker pose in Godot
4. Export a bounded edited scene and compare attributes

### Fixture, reset and unavailable path

Scenario: `blender-round-trip`. Fixture: Original Blender-source mesh with UV seams, vertex colors, rig, pose and unit markers.

Reset ownership: Restore approved source and remove only generated interchange outputs.

Limits and unavailable route: Blender/plugin versions require probes. Godot export may not preserve every authoring feature.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Axes/scale match markers
- UV/color attribute counts/hash policy hold
- Bone names and reference pose preserved
- Unsupported attributes reported explicitly

### Failure and negative controls

- Missing external texture rejects or labeled unresolved
- Malformed/unknown extension cannot silently lose data

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
