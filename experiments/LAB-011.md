### Fixture, reset and unavailable path

Scenario: `camera-rig`. Fixture: Original player-height landmarks, arch and narrow corner.

Reset ownership: Restore camera transform, target, projection and spring-arm state.

Limits and unavailable route: Comfort remains a later human gate; screen-space assertions are bounded proxies.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Camera avoids clipping in supported preset
- Projection label matches actual mode
- Player remains in declared safe frame
- Reset restores reference composition

### Failure and negative controls

- Missing target rejects
- Invalid near/far range rejects
