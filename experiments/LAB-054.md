### Interaction

1. Play an idle pose
2. Trigger bounded physical fall
3. Wait for settling
4. Blend toward a chosen recovery pose

### Fixture, reset and unavailable path

Scenario: `ragdoll-recovery`. Fixture: Original simple rig, floor and two recovery poses.

Reset ownership: Disable simulation and restore pose/transforms/constraints.

Limits and unavailable route: Exact physical-bone API requires probe; no general retargeting guarantee.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Physical mode changes actual bone transforms
- Fall remains within resource bounds
- Recovery ends in valid animation state
- Reset clears physics velocities

### Failure and negative controls

- Missing recovery pose rejects
- Unsettled timeout reports incomplete recovery

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
