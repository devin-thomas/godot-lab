### Interaction

1. Select original corner/wall mesh
2. Paint vertex color ramp
3. Switch triangulation/reference view
4. Compare lit and authored output

### Fixture, reset and unavailable path

Scenario: `vertex-shade`. Fixture: Original quad/corner meshes with intentional shade boundaries.

Reset ownership: Restore vertex attributes, triangulation and comparison mode.

Limits and unavailable route: No claim that every imported format preserves colors without round-trip test.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Color data reaches shader
- Ramp follows intended vertices
- Triangulation artifact is visible/labeled
- Reset restores attribute hash

### Failure and negative controls

- Unknown vertex rejects
- Wrong color count refuses mutation

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
