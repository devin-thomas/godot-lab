Edit a tiny voxel volume and inspect meshing, collision and chunk seams.

### Interaction

1. Remove a marked voxel
2. Add a voxel at a boundary
3. Regenerate bounded mesh/collision
4. Walk and inspect seams

### Fixture, reset and unavailable path

Scenario: `voxel-quarry`. Fixture: Original small voxel chunks with deterministic material IDs.

Reset ownership: Restore voxel arrays and recreate affected mesh/collision.

Limits and unavailable route: Custom bounded meshing, not an implied built-in voxel engine.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Edit changes expected cells only
- Boundary surfaces have no cracks
- Collision follows committed mesh
- Same voxel data gives same topology signature

### Failure and negative controls

- Out-of-bounds edit rejects
- Cancelled rebuild cannot replace last complete chunk

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
