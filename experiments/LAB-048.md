### Interaction

1. Assemble a small linkage
2. Pull an end body
3. Switch one joint recipe
4. Compare travel limits and reset

### Fixture, reset and unavailable path

Scenario: `joint-arcade`. Fixture: Original pendulum, spring and slider fixtures.

Reset ownership: Restore transforms/velocities and reconstruct owned joints.

Limits and unavailable route: Physics tolerances are host/version-specific; no bit-identical replay promise.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Pin maintains declared pivot tolerance
- Spring response changes with profile
- Slider stays within allowed travel
- Reset restores baseline linkage

### Failure and negative controls

- Missing body refuses joint
- Negative/invalid parameters reject before mutation

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
