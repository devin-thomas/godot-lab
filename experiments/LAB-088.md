### Fixture, reset and unavailable path

Scenario: `source-bound-capture`. Fixture: Original game-only route and wrong-source/black-frame fixtures.

Reset ownership: Stop owned recording and restore isolated provider profile only.

Limits and unavailable route: Provider capture distinct from Godot movie writing. Credentials stay local; no desktop fallback.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Declared source matches build/window identity
- Black/flat output rejects proof
- Artifact includes scenario/build provenance
- Stop finalizes on failure

### Failure and negative controls

- Wrong source refuses capture
- Unavailable provider reports gate without success-shaped movie substitute
