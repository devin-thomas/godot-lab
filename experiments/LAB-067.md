### Interaction

1. Select original symbol
2. Place it on flat/curved fixtures
3. Switch supported projection/fallback profile
4. Inspect seams and reset

### Fixture, reset and unavailable path

Scenario: `decal-printing`. Fixture: Original paint symbols and calibration surfaces.

Reset ownership: Remove lab marks and restore receiver/material profiles.

Limits and unavailable route: Decal renderer support is probed; mesh fallback is not identical projection.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Mark lands on selected receiver
- Excluded receiver remains clean
- Fallback is labeled
- Instance budget is enforced

### Failure and negative controls

- Unsupported Decal path reports gate
- Invalid receiver or texture refuses placement

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
