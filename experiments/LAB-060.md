### Interaction

1. Choose a motif region
2. Paint bounded pixels
3. Apply to wall/trim/floor samples
4. Compare nearest and supported minification modes

### Fixture, reset and unavailable path

Scenario: `atlas-author`. Fixture: Original 256 x 256 proposed motif sheet with padded swatches and trim regions.

Reset ownership: Restore original atlas pixels and sample UVs.

Limits and unavailable route: Texture size is a project choice. Whole-atlas repeat is not subregion tiling.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Pixel edits affect intended region only
- Padding prevents declared sample bleed
- Repeated trim stays in assigned region
- Undo restores atlas hash

### Failure and negative controls

- Out-of-region stroke rejects
- Invalid UV rectangle refuses apply

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
