### Interaction

1. Select original shader
2. Move a bounded uniform slider
3. Compare synchronized views
4. Introduce a controlled compile failure and recover

### Fixture, reset and unavailable path

Scenario: `shader-bench`. Fixture: Original rim, dissolve and palette shaders plus calibration mesh.

Reset ownership: Restore known-good shader and all uniform defaults.

Limits and unavailable route: Shader language/backend availability requires compile probes.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Uniform changes intended pixels
- Reference view stays unchanged
- Compile failure is shown
- Recovery restores valid output

### Failure and negative controls

- Unknown uniform rejects
- Invalid shader never overwrites known-good fixture

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
