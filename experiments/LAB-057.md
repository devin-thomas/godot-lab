### Interaction

1. Dispatch baseline courier
2. Move original obstacle
3. Request bounded rebake
4. Compare new path after synchronization

### Fixture, reset and unavailable path

Scenario: `navmesh-workshop`. Fixture: Original small bake region with movable blocker and path markers.

Reset ownership: Restore blocker, mesh and navigation map state.

Limits and unavailable route: Bake/source signatures are version-sensitive probes; avoidance alone is not rebaking.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- New committed path avoids moved obstacle
- Path switches only after map sync
- Failed bake preserves previous region
- Reset restores baseline path

### Failure and negative controls

- Invalid source geometry refuses bake
- Cancelled bake cannot mount late map

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
