2. Choose bounded original input

### Fixture, reset and unavailable path

Scenario: `compute-garden`. Fixture: Original integer/float transform vectors and bounded particle-state arrays.

Reset ownership: Free owned buffers/pipelines and restore input data.

Limits and unavailable route: RenderingDevice/backend/thread ownership signatures need probes. No Compatibility compute promise.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- GPU/reference outputs match defined tolerance
- Readback identifies actual backend
- Unsupported route reports unavailable
- Repeated runs release allocated resources

### Failure and negative controls

- Oversized dispatch rejects
- Shader failure preserves reference result without claiming GPU success

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
