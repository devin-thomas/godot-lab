### Interaction

1. Aim at original targets
2. Place a blocker
3. Switch query shape/mask
4. Fire and inspect hit receipt

### Fixture, reset and unavailable path

Scenario: `aim-range`. Fixture: Original target plates, thin blocker and collision-layer markers.

Reset ownership: Restore targets, query profile and projectile budget.

Limits and unavailable route: No weapon-art or commercial game content; continuous projectile proof is separate.

Use original bounded fixtures with hash/license/seed manifests. Readiness must name the actual missing adapter and a useful labeled fallback if possible. Fixture replay does not establish device/provider support.

### Positive acceptance

- Occluder prevents hidden target hit
- Ray/shape outcomes match documented geometry
- Mask excludes declared targets
- Hit receipt identifies stable object and position

### Failure and negative controls

- Zero-length query rejects
- Invalid mask/profile returns explicit error

Additionally exercise reset/exit during the longest operation, repeated entry and fixture isolation. Observe real mechanisms; never assign the expected final result to make the assertion pass.
