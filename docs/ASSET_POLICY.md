# Asset and public-content policy

The public core uses original procedural or authored meshes, textures, tones, text, and fixtures. Reference games inform principles; their characters, textures, screenshots, videos, dialogue, music, and extracted files are not redistributed as project assets.

Each adopted external asset needs source URL, author, license, required attribution, modifications, and redistribution permission. Engine and tooling dependencies retain their own licenses. Fonts need an explicit license/provenance entry; a font installed on one machine is not permission to redistribute it.

Keep reference downloads, research frames, raw recordings, exports, save files, credentials, machine-specific configuration, and private operational notes outside public tracked files. Check captures for unrelated windows, account names, absolute paths, and embedded metadata before selecting any public evidence media.

The project LICENSE covers original project material, not all third-party dependencies or reference works. Public documentation should synthesize original rules and link to public originals rather than copying unpublished research.
